## End to End Machine Learning Project 

Tools Used : Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, Flask, HTML5, CSS, Bootstrap 5
 Developed a machine learning model to predict student math scores based on demographic and academic
 inputs.
 Performed data cleaning, feature engineering, and exploratory analysis to identify key predictors.
 Trained and evaluated multiple regression models including Linear Regression, Decision Tree Regressor, and
 Random Forest Regressor.
 Built an interactive web app using Flask and Bootstrap 5 for real-time predictions based on user input.
 Deployed the model locally to enable dynamic, user-friendly access to score predictions
